# Travel Fare Calculator

## Description
Write a short explanation of what the program does.

## Version 1 - Original Code Without Input Validation

- **Input:** Describe the passenger information requested by the program.
- **Process:** Explain how the program calculates the total fare.
- **Output:** Describe the information displayed to the user.
- **Validation:** State whether the original code checks for invalid inputs.

## Version 2 - Code With Input Validation

- **Input:** Describe the information entered by the passenger.
- **Process:** Explain how the program checks the inputs and calculates the fare.
- **Output:** Describe the results and any error messages.
- **Validation Rules:**
  - Passenger name: Must not be empty.
  - Distance: Must be a number greater than zero.
  - Number of passengers: Must be a positive whole number.
